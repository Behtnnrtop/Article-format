# Article Format

一个用于生成「文手年度总结」长图的网页小工具。项目基于原生 HTML、CSS 和 JavaScript 编写，可直接在浏览器中运行。

## 功能特点

- 实时编辑年度总结标题、作者信息、右侧竖排版头和月份内容
- 支持新增、删除多个内容段落
- 支持富文本编辑，包括加粗、斜体、下划线和删除线
- 支持调整标题字号、正文字号、行距、段落间距和模块间距
- 支持切换时间轴、月份标题、月份横线和竖排版头
- 支持背景色、文字颜色和字体设置
- 支持读取本机字体（需浏览器权限，推荐 Chrome 或 Edge）
- 支持手机分辨率预览
- 支持导出完整长图 JPG
- 支持按手机比例自动切图并导出 ZIP
- 编辑内容会自动保存在浏览器本地

## 使用方法

1. 打开 `index.html`
2. 在右侧编辑器中修改标题、作者、年份和段落内容
3. 根据需要调整颜色、字体、字号、间距和显示选项
4. 点击 `导出长图JPG` 生成完整长图
5. 或点击 `导出已切图的JPG` 生成适合手机浏览的切图压缩包
